LAD Workspace
Project tracker + calendar, synced via Dropbox
First-time setup (3 minutes):
  1. Go to dropbox.com/developers/apps
  2. Create App → Scoped Access → App folder → name it LADWorkspace
  3. In Permissions tab, tick: files.content.read + files.content.write, then Submit
  4. In Settings tab, add this page's URL to Redirect URIs
  5. Copy your App key below and click Connect
Found in your app's Settings tab on the Dropbox App Console
